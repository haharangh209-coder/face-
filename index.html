얼굴 위치 · 회전 추적

카메라 권한을 직접 요청한 뒤 얼굴 하나를 추적합니다. 카메라 권한은 브라우저가 표시하는 창에서 사용자가 허용해야 합니다.

시작 버튼을 누르면 카메라 권한 요청이 표시됩니다.
⚠ 얼굴이 카메라에 너무 가까울 수 있습니다. (거리 추정값 기준)

권한이 허용되지 않나요?

  1. 이 페이지가 https://로 시작하는 GitHub Pages 주소인지 확인하세요.
  2. Chrome 주소창 왼쪽 사이트 설정에서 카메라를 허용으로 바꾸세요.
  3. 페이지를 새로고침하고 다시 시작 버튼을 누르세요.
  4. 학교/회사 기기에서 설정이 잠겨 있으면 관리자 정책 때문에 허용할 수 없을 수 있습니다.

실시간 측정값

X/Y/Z는 일반적인 얼굴 모델을 이용한 근사값입니다. 실제 거리계 측정값이 아닙니다.

X · 좌우 위치—
Y · 상하 위치—
Z · 거리 추정—
Pitch · 위아래 회전—
Yaw · 좌우 회전—
Roll · 좌우 기울기—
상태대기 중

처음 실행할 때 얼굴 인식 모델과 OpenCV.js를 인터넷에서 불러옵니다. 네트워크에서 외부 라이브러리를 차단하면 실행되지 않을 수 있습니다.
